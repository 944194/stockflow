# StockFlow Frontend

The frontend for **StockFlow**, a SaaS inventory management application built with React and Vite.

## Features

- User signup and login
- Inventory dashboard and stock summaries
- Product creation, editing, deletion, and search
- Low-stock alerts
- Account and inventory settings

## Technologies

- React
- Vite
- CSS
- Lucide React icons

## Local Development

From the `frontend` directory, install dependencies:

```bash
npm install
```

Create a `.env` file containing:

```env
VITE_API_URL=http://localhost:5000
```

Start the development server:

```bash
npm run dev
```

## Deployment

The frontend is deployed on Vercel.
